# Full-site audit, October 2026

Started 7 October 2026 (week 5, Tony's Pizza Fantasy), against production
`1a2bf09`. Every number below was read from production through the Probe
workflow or from Sleeper's public feeds, not reasoned about. This file is the
findings register: one row per finding, fixed or not, written so a later round
can pick it up without redoing the audit.

Status words: **FIXED in PR #n**, **NOT DONE** (with the fix and its size), or
**NEEDS ALEX** (a decision only he can make: money, a schema change, or a
protected area).
